# M5 results: Query understanding, metadata and chunking

All numbers come from run directories under `experiments/` created on 2026-10-18 (named
below). Primary labels: `golden_v1` (dev 85 / test 127 answerable queries). Base pipeline:
M4's `hybrid_weighted` (BM25F + dense bge-small, min-max, α on BM25). LLM steps use the
`query` role: **`ollama_chat/qwen2.5:3b-instruct` on the local RTX 3050** (ADR 0005), run with
`DOCSEEK_LLM_STRICT=1` so a provider error fails a run instead of silently degrading.

## Analysis

- **No component transferred from dev to test.** The dev gains of the context header plus the
  α re-tune (+0.034 over M4's hybrid) vanish on test (0.709 vs 0.709). Both were chosen on 85
  dev queries; with CIs of ±0.06 the dev lift was within what selection noise can produce.
  Per type, the header helps `freshness` and `factoid` and hurts `conceptual` on test.
- **The metadata stage does what it is for**: the superseded penalty removes stale hits
  (test StaleHit@5 0.20 → 0.00, freshness nDCG +0.20 vs M4), but only 2 of 10 stale-labelled
  test queries change, so the paired test cannot reach significance (minimum p with 2
  differing pairs is 0.5). The criterion needs more freshness queries, not a different method.
- **LLM query expansion with a 3B local model hurts or does nothing.** Rewrite is significantly
  worse (the rewrites drift from the docs' vocabulary); HyDE is neutral overall; decomposition
  hurts on the 8 dev multihop queries; filter extraction returned no filter for any of the 99
  dev queries (no query states one explicitly), so it only adds ~1.2 s. The final config therefore uses no
  router and no query-time LLM. A larger model (e.g. Gemini) may
  change this; it was not testable within today's free-tier quota.
- **Classifier accuracy is low (0.41–0.44)**, but routing quality is what matters and the
  router run shows no loss from misroutes because the routes barely differ.
- **Reranking after the metadata stage must use bounded scores**: cross-encoder logits can be
  negative, where a multiplicative penalty would *promote* a superseded doc; the freshness
  stage applies `sigmoid` first (unit test).
- **Recommendation:** keep `fresh_ctx` as the fast default (it equals M4's hybrid on test and
  removes stale hits) and rerank@20 as quality mode; no query-time LLM.
- **LLM cost of M5:** Ollama `qwen2.5:3b-instruct` 498 calls, $0; Gemini (before the switch)
  158 calls on 3.1-flash-lite + 24 on 3.5-flash-lite, $0.012 at list price on the free tier
  (not charged); OpenAI $0. Project ledger: OpenAI $0.933 of the $1.88 cap.
- **Harness fix found in M5:** `docseek eval grid` reused the base config's chunks for every
  grid point; a sweep over `chunks_file` reported identical numbers. Fixed (inputs are loaded
  per point); M2–M4 sweeps only changed retriever parameters and are unaffected.

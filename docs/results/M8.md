[`docs/benchmark_report.md`](../benchmark_report.md). Answer model `gemini/gemma-4-26b-a4b-it`

## Results

| Test (golden_m7, 147 answerable) | nDCG@10 | Recall@10 | p95 ms |
|---|---|---|---|
| BM25F | 0.693 | 0.850 | 6.7 |
| fresh_ctx (default) | 0.716 | 0.864 | 119.7 |
| rerank_fresh_ctx | 0.758 | 0.895 | 1,228.6 |

| Answers (60 test q: 47 answerable, 13 must abstain) | one-shot | agentic | agentic, no FS |
|---|---|---|---|
| Faithfulness / answer relevancy | 0.952 / 0.912 | 0.961 / 0.917 | 0.956 / 0.910 |
| Contextual recall / citation support | 0.767 / 0.976 | 0.853 / 0.907 | 0.907 / 0.946 |
| Evidence recall@10 | 0.872 | 0.915 | 0.883 |
| Correct abstentions · wrong abstentions | 13/13 · 2/47 | 13/13 · 1/47 | 13/13 · 1/47 |
| Mean / max steps · removed citations | 1 / 1 · 0 | 2.8 / 6 · 0 | 2.5 / 6 · 0 |
| Wall p95 · compute p95 (s) | 80.2 · 79.0 | 102.3 · 52.6 | 63.8 · 33.3 |

- **The agent retrieves more of the right evidence** (0.915 vs 0.872 evidence recall; contextual
  recall 0.853 vs 0.767) but **cites less precisely** (citation support 0.907 vs 0.976, the
  only DeepEval metric whose CIs separate). Faithfulness and relevancy are the same within CIs.
- **FS tools barely matter here**: the agent called `ls`/`grep` 8 times in 60 questions, and
  without them it scored the same or better (contextual recall 0.907). The search tool does
  the work; the graph tool was never chosen.
- **Abstention works**: all 13 must-abstain questions (unanswerable, or no readable relevant
  section for the principal) were abstained on in every mode; no fabricated citation reached
  an answer (the post-check removed 0). The first report counted no-access permission queries
  as answerable; `m8_answer_summary` fixes that definition.
- **Latency is dominated by the free-tier answer model** (one ~2k-token Gemma call ≈ 13 s p50);
  retrieval is ~0.1 s (1.2 s with rerank) and tool calls 0.3 s p50 per question.
- **int8 quantization** cuts vector RAM 4× with ANN recall 0.997 when rescoring (0.955
  without); `hnsw_ef` changes recall, not latency, at 1.4k vectors.
- **Cost**: answer generation $0 (free tier); ≈ $1.20 (one-shot) / $2.39 (agentic) per 1k
  questions at flash-lite list prices from measured tokens. M8 OpenAI spend (DeepEval):
  $0.410 (ledger total $1.343 of the $1.88 cap). Gemini/Gemma: free tier.
- **Environment issues met**: Gemini 3.1-flash-lite quota exhausted again, 2.5-flash-lite
  closed to new users → Gemma 4 (ADR 0007); Gemma's 16k tokens/min limit and one dropped
  connection stopped the strict answer run three times (resumed from the cache); the
  partial runs are kept and used only for uncached latency (`m8_answer_latency`).
- **Packaging**: Dockerfile + compose `api`/`ui` (quick demo on the mini corpus with a hash
  embedder by default), `docseek demo build`, Makefile, CI smoke job.

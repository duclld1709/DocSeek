# M4 plan: hybrid retrieval + reranking

1. `hybrid/normalization.py` (min-max, z-score) and `hybrid/fusion.py` (own RRF, weighted sum
   after normalisation, `HybridRetriever` over child retrievers to depth 50). Hand-computed
   tests incl. empty lists, duplicate ids, ties.
2. Qdrant-native hybrid: sparse vector `bm25` (doc-side BM25 tf weights, `modifier: idf`) next
   to `dense`; `prefetch` both + `FusionQuery(RRF)`; one comparison run.
3. `rerank/cross_encoder.py`: fastembed `BAAI/bge-reranker-base`; `RerankedRetriever`
   (first stage top-N → rerank → k). N ∈ {20, 50} (+100 if fast enough).
4. Register `hybrid`, `qdrant_hybrid`, `rerank` in the runner; Leakage probes for each.
5. Dev experiments: RRF k ∈ {30, 60}; weighted α ∈ {0.3, 0.5, 0.7} (min-max); best fusion +
   rerank N grid; quality–latency PNG. Test once for final config(s).
6. Golden v2 (`eval/pooling.py` + `docseek eval pool`): pool top-10 of BM25F, dense, best
   hybrid for every query; judge (OpenAI nano, cached, budget-capped) unlabelled pairs;
   `reviewed: false`, `annotator: judge model`. Report v1 (primary) and v2.
7. Hard-negative check: share of golden hard negatives ranked below the positive, before and
   after rerank.
8. Docs: results/M4, milestones/M4, progress; tag `m4-hybrid`.

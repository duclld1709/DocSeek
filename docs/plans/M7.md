# M7 plan: OCR + multimodal

Decisions: render with PyMuPDF `Story` (HTML+CSS → PDF, no GTK/browser), ground truth = text
layer of the clean PDF (exactly what is printed, in reading order); CER/WER via rapidfuzz
Levenshtein (hand-worked unit tests). Vision LLM = `llm.vision` (Gemini 3.1-flash-lite, free
tier, ≤ 500/day: 30 OCR pages + ≤ 150 captions). Golden v1 is never edited: scan/image queries
go to a new `data/golden/golden_multimodal.jsonl` (Claude-written, `origin: claude`) and the
"overall" eval uses v1 + that file.

# M2 plan: lexical search (TF-IDF, BM25, BM25F)

1. `lexical/tokenizer.py`: `TokenizerConfig(lowercase, stopwords, stem, code_aware)`; code-aware
   keeps `@app.get`, `response_model`, `BackgroundTasks` and adds their parts. Snowball stemmer
   (`py-rust-stemmers`). Hand-worked unit tests.
2. `lexical/fields.py` + `lexical/inverted_index.py`: per-field postings (title, section_path,
   body, code fences), df, field lengths; pickle to `data/index/bm25/<hash>.pkl`.
3. `lexical/bm25.py` (BM25F with per-field length norm; single field = classic BM25, Lucene
   idf) and `lexical/tfidf.py` (log-tf × idf cosine). Hand-computed score tests.
4. `lexical/retriever.py`: `LexicalRetriever` with ACL + `MetadataFilter` pre-filter mask;
   `Bm25sRetriever` (reference, same tokenizer). Leakage = 0 tests. Register `bm25`, `tfidf`,
   `bm25s` in `eval/runner.py`.
5. `eval/grid.py` + `docseek eval grid`: cartesian sweep over config keys on dev, summary JSON;
   `scripts/plot_heatmap.py` → `docs/results/img/m2_bm25_grid.png`.
6. CLI `docseek index bm25`, `docseek search`. CI `eval-gate` job (BM25 on mini corpus vs
   `tests/fixtures/baseline_metrics.json`, Leakage must be 0).
7. Experiments (dev): tfidf, bm25 default (1.2/0.75), grid 4×4, field-weight choice, ablations
   (no stem / no code-aware / no field weights), bm25s once. Test: tfidf, bm25 default, tuned.
8. Failure analysis of the 15 worst dev queries; ADR 0001 → Accepted; results/M2, milestones/M2.

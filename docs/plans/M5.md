# M5 plan: query understanding, metadata, chunking

Base pipeline: `hybrid_weighted` (M4 fast default); every component wraps it. LLM calls use
the generator role (Gemini flash-lite, free tier, rpm 10, cached).

1. `query/classifier.py` (rules → LLM structured output), accuracy vs golden `qtype` (all
   splits, predicted types only). `docseek eval classify`.
2. `query/filters.py`: LLM → `MetadataFilter`, unknown doc types dropped, fallback when the
   filter empties results (trace event). Test with ScriptedLLM.
3. `query/rewrite.py`: multi-query (n=3), HyDE, decompose; each fuses with RRF; LLM failures
   degrade to the original query.
4. `query/freshness.py`: `s·(1+β·e^(−Δ/τ))`, ×(1−p) for deprecated and superseded docs.
   StaleHit@5 before/after (dev → test), paired test.
5. Runner types `classify_route`, `expand` (rewrite|hyde|decompose), `freshness`; router maps
   qtype → route; HyDE only for qtypes where it beats rewrite on dev.
6. Chunking: `ingest/strategies.py` (`fixed_256` doc windows, `section_ctx` header in
   `text_for_embedding`); `docseek ingest-variants` writes `chunks_<strategy>.jsonl`;
   `ExperimentConfig.chunks` selects the file. Dev ablation on hybrid; ADR 0004.
7. Ablation: final router config minus one component at a time (dev); test once for final.
8. Leakage probes for every new wrapper and router path; docs; tag `m5-query`.

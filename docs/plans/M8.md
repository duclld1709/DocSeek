flash-lite, free tier, 500/day) for all 3 answer modes so they differ only in the pipeline.

abstain rate). DeepEval runs through an adapter on our client (cache + BudgetGuard + ledger,
judge `gpt-5.4-nano`); pilot on 5 answers first, run cap $0.70 (OpenAI ≈ $0.95 left).

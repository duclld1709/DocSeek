# M0 — Foundation & Project Setup (đề bài)

> Buổi 01. Tag tham chiếu: `m0-setup`. File này là **đề bài**, không chứa lời giải.
> Tự làm trước, sau đó so sánh với tag tham chiếu.

## Mục tiêu

Có một repo sạch, chạy được, CI xanh, và có tài liệu tổng quan về bài toán search. Mọi
milestone sau đều xây trên nền này, nên các quyết định ở đây (ID ổn định, interface, fake,
config, logging) phải đủ chắc để không phải sửa lại.

## Việc cần làm

1. **Khởi tạo project** bằng `uv init --package` (Python 3.12). Cấu hình `pyproject.toml`
   gồm deps cơ bản, nhóm `dev`, và cấu hình ruff (line length 100), mypy (strict cho
   `core/`) và pytest (marker `integration`, `e2e`).
2. **`.gitignore`** đúng theo spec: không commit `.env`, `data/raw`, index; vẫn giữ
   `data/golden`, `data/internal_kb`, `data/scans/ground_truth`.
3. **`core/models.py`**: các model ở PROJECT_SPEC §4.2 (Section, Chunk, Query, ScoredHit,
   RetrievalResult, TraceEvent, kèm Provenance, MetadataFilter, LLMResponse).
4. **ID ổn định** theo §3.5 (`doc_id`, `section_id`, `chunk_id`), có hàm dựng và hàm suy
   ngược từ chunk về section.
5. **`core/interfaces.py`**: các `Protocol` Retriever, Embedder, Reranker, LLMClient.
6. **`testing/fakes.py`**: `HashEmbedder`, `IdentityReranker`, `ScriptedLLM`.
7. **`core/config.py`**: đọc `.env` (key là secret) và `configs/{corpus,principals,models}.yaml`.
   **`core/logging.py`**: structured logging, không bao giờ log giá trị key.
8. **CLI Typer**: `docseek --help` và `docseek doctor`. `doctor` kiểm tra Qdrant, Neo4j, key
   (chỉ báo có/không) và Tesseract.
9. **`docker-compose.yml`**: Qdrant và Neo4j, có healthcheck và volume.
10. **`docseek data fetch`**: lấy FastAPI docs (`docs/en/docs` và `docs_src`) tại commit
    đã pin, ghi `data/raw/MANIFEST.json`.
11. **`tests/fixtures/mini_corpus/`**: khoảng 10 file md nhỏ có đủ các đặc thù của FastAPI
    docs.
12. **pre-commit** (ruff và một bước chặn commit `.env`) và **GitHub Actions CI** (`uv sync`
    → ruff → mypy → pytest unit → coverage).
13. **Tài liệu**: `README.md` (khung), `docs/overview.md`, `docs/architecture.md` (nháp),
    `docs/adr/0001-*.md`.

## Acceptance criteria

- [ ] `uv sync && uv run docseek doctor` chạy được trên máy sạch, chỉ cần docker.
- [ ] `docker compose up -d` cho ra Qdrant và Neo4j ở trạng thái healthy.
- [ ] `uv run pytest` xanh, CI xanh trên GitHub.
- [ ] `data/raw/MANIFEST.json` có đúng commit `b23d78f2ce4e7b3ea48a59f51ca249690d9fd02c`.

## Gợi ý tự kiểm tra (không phải lời giải)

- Chạy `doctor` khi docker **đang tắt**: lệnh có báo lỗi rõ ràng không, exit code là bao nhiêu?
  Thiếu key hoặc Tesseract thì có nên làm lệnh fail ở M0 không?
- Đặt một key giả vào `.env` rồi grep output của `doctor` và log: giá trị key có lọt ra không?
- Chạy `data fetch` hai lần liên tiếp: lần hai có clone lại không? Đổi commit pin thì sao?
- So sánh sha256 trong MANIFEST giữa Windows và Linux. Có khớp không, và vì sao có thể không?
- Clone của bạn có giữ đủ history để M1 lấy được `updated_at` bằng `git log -1 -- <file>` không?
- Mở vài file thật trong FastAPI docs: dòng nào bắt đầu bằng `#` mà **không phải** heading?
  Heading nào **không có** anchor?
  Include `{* ... *}` resolve tương đối so với thư mục nào?
- Thử commit một file `.env` (kể cả `git add -f`): pre-commit có chặn không?

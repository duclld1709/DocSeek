# M6 — Knowledge Graph + Filesystem Search (đề bài)

> Buổi 07. Tag tham chiếu: `m6-graph-fs`. File này là **đề bài**, không chứa lời giải.
> So sánh trên **golden_v1**, đặc biệt lát `multihop`, cùng split, cùng metric.

## Mục tiêu

Retrieval theo quan hệ (multi-hop) bằng knowledge graph, và một "filesystem" để agent điều
hướng corpus như developer — cả hai đều enforce ACL trong code.

## Việc cần làm

1. **Schema** Neo4j (Page, Section, APIElement, Concept, CodeExample, Version, KBDoc và các
   cạnh PART_OF, LINKS_TO, MENTIONS, SHOWS, USES, CHANGED_IN, SUPERSEDES, REFERENCES), ghi vào
   `graph/schema.py` và `docs/architecture.md`.
2. **Extraction**: luật (link, identifier trong backtick), **AST của `docs_src`** (import + tên
   được dùng), release notes → Version; LLM (có cache) trích `Concept`, giới hạn số trang.
   **Entity resolution**: chuẩn hoá tên, gộp alias. Kiểm tra: concept nào quá phổ biến?
3. **Loader** idempotent (chạy lại không nhân đôi node/cạnh).
4. **Graph retriever**: entity linking (exact + fuzzy), 3–5 **Cypher template có tham số**;
   ACL lọc ngay trong Cypher; trả kèm đường đi làm giải thích. **Không** cho LLM tự sinh Cypher
   (viết ADR).
5. Fuse graph với hybrid M5 và đo trên `multihop` (dev để tune, test một lần).
6. **Projection** corpus thành cây markdown (`<!-- section_id -->`, `_index.md`) và **FS tools**
   `ls/find/grep/cat`: sandbox (chặn `..`, symlink, đường dẫn tuyệt đối), ACL theo principal,
   giới hạn output, trace mỗi lần gọi. `_index.md` có làm lộ tiêu đề trang bị giới hạn không?

## Acceptance criteria

- [ ] Test path traversal, test ACL cho FS tools, test các Cypher template trên graph fixture.
- [ ] Trên `multihop`: graph (hoặc graph + hybrid) cải thiện Recall@10 so với hybrid M5, **hoặc**
      phân tích bằng số vì sao không.
- [ ] Mục "When graph beats vector retrieval (and when it doesn't)" có ví dụ cụ thể.
- [ ] Leakage = 0 cho graph và FS.

## Câu hỏi để tự kiểm tra

- Một entity xuất hiện ở 50% section thì có ích gì cho linking không?
- File bị ẩn với principal nên trả lỗi gì để không lộ rằng nó tồn tại?
- Vì sao kiểm tra ACL hai lớp (trong Cypher và sau đó) vẫn đáng làm?

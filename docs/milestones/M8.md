# M8 — Agent, API, UI, Benchmark & Ship (đề bài)

> Buổi cuối. Tag tham chiếu: `v1.0.0`. File này là **đề bài**, không chứa lời giải.
> Mọi số trong README và benchmark report phải đến từ `experiments/`.

## Mục tiêu

Ghép retrieval M2–M7 thành sản phẩm demo được (agent + API + UI + docker), đo chất lượng câu
trả lời và tradeoff production, viết README đủ để người khác clone và chạy.

## Việc cần làm

1. **Agent loop tự viết** qua tool calling: `max_steps` (6), timeout, budget mỗi câu hỏi.
   Tools: `search(mode, filters)`, `graph_search`, `ls/find/grep/cat`, `get_section`,
   `image_search`. Mô tả tool chính là "search skills" của agent.
2. **Principal do server inject**; agent không đổi được (viết test). Tool output bọc
   delimiter (rủi ro prompt injection từ tài liệu).
3. **Citation `[section_id]` bắt buộc** + hậu kiểm (chỉ giữ section đã retrieve); thiếu bằng
   chứng thì abstain kèm gợi ý.
4. So sánh 3 chế độ: one-shot RAG (router + hybrid + rerank), agentic, agentic không FS tools.
   Chất lượng câu trả lời bằng DeepEval (Faithfulness, AnswerRelevancy, ContextualRecall,
   GEval citation) — judge đi qua cache + budget của mình; số bước, latency, cost.
5. **API** FastAPI `/search`, `/ask`, `/health`, `/traces/{id}`; principal từ `X-Principal`;
   test bằng `TestClient` + LLM giả.
6. **UI** Streamlit: Compare / Answer (citation bấm được, đoạn nguồn, trang PDF) / Trace / Eval.
7. **`docseek bench`**: quality (CI, theo qtype), p50/p95/p99 warm × 3, RAM, docker stats, disk,
   build time, $/1k query; int8 quantization; HNSW `ef` × 3 giá trị. Ghi cấu hình máy.
8. **Đóng gói**: `docker compose up` (qdrant, neo4j, api, ui), quick demo < 2 phút,
   `make demo`, README §9, benchmark report + failure analysis, release `v1.0.0`.

## Acceptance criteria

- [ ] Clone sạch → `docker compose up` → demo chạy theo README.
- [ ] Benchmark report đủ cột với số đo thật.
- [ ] Coverage ≥ 80% cho `core/`, `eval/`, `lexical/`, `hybrid/`, `fs/`; tổng ≥ 70%.
- [ ] Agent: test chứng minh không leak ACL, không vượt `max_steps`, citation hợp lệ.

## Câu hỏi để tự kiểm tra

- Latency của agent gồm những gì? Phần nào là chờ rate limit của free tier?
- Với corpus ~1.4k vector, `hnsw_ef` có tác dụng không? Vì sao?
- DeepEval tự gọi OpenAI — làm sao để nó vẫn đi qua budget và cache của bạn?
- Agent abstain nhiều hơn one-shot: đó là lỗi hay là hành vi đúng?

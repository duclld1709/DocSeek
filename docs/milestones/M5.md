# M5 — Query Understanding, Metadata & Chunking (đề bài)

> Buổi 06. Tag tham chiếu: `m5-query`. File này là **đề bài**, không chứa lời giải.
> So sánh trên **golden_v1**, cùng split, cùng metric. Mọi LLM call phải qua cache + budget.

## Mục tiêu

Làm cho search "hiểu" query: phân loại, viết lại, tách, trích filter, định tuyến; dùng metadata
(độ mới, bản bị thay thế) như một tín hiệu; chọn chiến lược chunking bằng số đo.

## Việc cần làm

1. **Classifier `qtype`**: luật rẻ trước (identifier, từ chỉ độ mới), LLM structured output sau.
   Đo **accuracy** so với nhãn `qtype` của golden (loại nào không suy ra được từ chữ thì bỏ ra).
2. **Trích filter** (`doc_type`, `source`, ngày, version) thành `MetadataFilter`. Nếu filter làm
   rỗng kết quả thì **fallback** bỏ filter và ghi trace. Chứng minh filter không thể nới ACL.
3. **Multi-query rewrite**, **HyDE**, **decompose** (cho `multihop`). So sánh HyDE với rewrite
   trên dev **theo qtype**, kèm latency và cost/query.
4. **Router**: qtype → pipeline. Chỉ dùng một kỹ thuật cho qtype mà nó thực sự có lợi trên dev.
5. **Metadata**: freshness boost `s·(1+β·e^(−Δ/τ))`, phạt `deprecated` và doc bị `supersedes`.
   Đo **StaleHit@5** trước/sau. Cẩn thận: điểm của retriever có thể âm không?
6. **Chunking**: `fixed_256`, `section`, `section+context_header` trên cùng golden mức section.
   Strategy nào làm mất section khỏi tập có thể trả về? Có cần chỉnh lại trọng số fusion không?
7. **Ablation**: tắt từng thành phần một trên dev; chạy `test` **một lần** cho cấu hình cuối.
8. LLM lỗi (429, timeout, JSON sai) thì **degrade** về query gốc; hết budget thì **dừng**.

## Acceptance criteria

- [ ] Bảng lift theo từng thành phần (ablation), cắt theo `qtype`.
- [ ] StaleHit@5 giảm khi bật supersedes/freshness, có kiểm định.
- [ ] Test fallback khi filter rỗng; Leakage = 0 trên **mọi** đường đi của router.
- [ ] ADR về chunking strategy được chọn.
- [ ] Chi phí LLM của milestone lấy từ trace.

## Câu hỏi để tự kiểm tra

- Rule "latest/current → freshness" bắt được bao nhiêu query freshness thật trong golden?
- Reranker đặt trước hay sau bước freshness? Vì sao thứ tự quan trọng?
- Một kỹ thuật tăng nDCG trung bình nhưng giảm ở một qtype: router xử lý thế nào?

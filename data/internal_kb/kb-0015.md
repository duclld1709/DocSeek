# Python service template { #python-service-template }

## Status { #status }

This ADR documents the internal service template maintained by the platform-team. Please note that this specific template version is now deprecated and has been superseded by newer architectural standards. Engineering teams should no longer initialize new projects using this repository.

## Implementation details { #implementation-details }

Historically, all new Python services were generated from this template, which mandates the use of Python 3.10. This version was selected to balance compatibility with our container orchestration layer and the need for modern type-hinting features. 

Dependency injection within our FastAPI routes relies heavily on the `Depends` utility to maintain loose coupling between business logic and infrastructure resources. Developers are required to declare dependencies using default-value style parameters. For example, database access is handled via `db = Depends(get_db)`. This pattern ensures that the FastAPI dependency graph can correctly resolve and inject necessary objects during the request lifecycle, while also simplifying unit testing by allowing the injection of mock objects during test execution.

## Maintenance and migration { #maintenance-and-migration }

While this template served as the foundation for our early microservices, the platform-team has moved toward a modernized template that includes enhanced observability hooks and improved middleware configurations. Teams currently operating services built on this deprecated template are encouraged to evaluate their upgrade path during regularly scheduled maintenance cycles. We advise against backporting complex features into this legacy structure, as it lacks the necessary abstraction layers for our current deployment pipeline requirements. For specific migration assistance, please reach out to the platform-team via our internal communication channels.

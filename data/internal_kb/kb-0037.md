# Postmortem of the January 2026 payout delay { #postmortem-of-the-january-2026-payout-delay }

## Summary { #summary }

On 2026-01-14, the payments-team experienced a service disruption resulting in a 6-hour delay for scheduled merchant payouts. The outage was triggered by the expiration of an external bank SFTP certificate, which prevented our automated batch processing jobs from successfully transmitting payment files to the clearing house. During this window, all outbound transaction files were held in an internal queue until the certificate was rotated.

## Timeline { #timeline }

- 08:00 UTC: Automated batch job failed to initiate due to a TLS handshake error with the bank SFTP server.
- 08:15 UTC: Sentry alerts triggered for persistent connection timeouts in the payments-processor service.
- 09:30 UTC: On-call engineer identified the certificate expiration via manual inspection of the connection logs.
- 11:30 UTC: New certificate requested from the banking partner and received via secure channel.
- 13:30 UTC: Certificate rotated in the production environment and verified via connectivity test.
- 14:00 UTC: Backlog of delayed payouts processed and cleared.

## Root cause { #root-cause }

The root cause was an expired bank SFTP certificate. While our internal systems monitor certificate validity for internal services, the external banking partner's certificate lifecycle was not tracked within our automated monitoring suite. The lack of proactive notification from the bank and the absence of an automated check for this specific external dependency led to the failure.

## Action items { #action-items }

- Implement automated monitoring for all external partner certificate expiration dates using a dedicated cron job in our infrastructure repository.
- Configure automated alerts for certificate expiration 30 days prior to the cutoff date.
- Establish a formal communication protocol with the banking partner to receive early warnings for upcoming security credential rotations.
- Update the payments-processor documentation to include manual certificate rotation steps to reduce recovery time in future incidents.

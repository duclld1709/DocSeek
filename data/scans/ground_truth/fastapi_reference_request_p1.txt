Request class
You can declare a parameter in a path operation function or dependency to be of type Request and then
you can access the raw request object directly, without any validation, etc.
Read more about it in the FastAPI docs about using Request directly
You can import it directly from fastapi:
from fastapi import Request
Tip:
When you want to deﬁne dependencies that should be compatible with both HTTP and WebSockets, you
can deﬁne a parameter that takes an HTTPConnection instead of a Request or a WebSocket.
API reference: fastapi.Request
